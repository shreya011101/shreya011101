## Featured project

### [Mandate Guardian](https://github.com/shreya011101/mandate-guardian)

A backend control tower for recurring financial commitments. It forecasts upcoming payments, distinguishes manual actions from expected auto-debits, and preserves trustworthy state changes through explicit business commands.

Built with Java 21, Spring Boot, PostgreSQL, Flyway, Testcontainers, Docker Compose, and GitHub Actions.

**Engineering highlights**
- Calendar-correct due-date calculation in the user's IANA time zone
- Idempotent writes that make client retries safe
- Explicit payment lifecycle actions with audit and transactional-outbox records
- A 1–90 day cash forecast that separates manual payments from auto-debits
